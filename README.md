# Galaxy Glide 2.0
Interactive solar-system mission game (React + Vite + Three.js).

    npm install
    npm run dev      # local dev
    npm run build    # outputs dist/index.html, one self-contained file

Deploy: push to GitHub and import into Vercel/Netlify (build: `npm run build`, output: `dist`), or upload `dist/index.html` to any static host.
`server-legacy/` is the original Google-login backend, unused in v2 (progress is saved in localStorage)....
